# Two-Sentence Horror — entry

A program/v1 entry for the make.fun "Two-Sentence Horror"
bounty. `main.py` writes exactly two sentences to
`/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that variable is set).

The story:

> Our toddler learned to count the stairs aloud: thirteen, every morning, proud as a bell. There are twelve, and this morning she counted down.

There are twelve stairs. See `CANDIDATES.md` for the full
draft list this winner was picked from.
